# DeckAtlas v0.3.0-beta.2

实验性 Pre-release，面向愿意反馈问题的 Apple Silicon Mac 用户。不是已完成生产安全与
升级验收的正式版本。官网：[DeckAtlas](https://keithdai.github.io/ppt-page-library/)。

## 本版变化

- Agent CLI 新增 `import`：明确授权后，将本地 PPTX、HTML、HTM、ZIP 索引到页库并生成预览。
  源文件留在原位置；部分失败会保留已索引内容并返回 `IMPORT_INCOMPLETE`，可重试补图。
- Agent 和桌面私有 CLI 的重型操作共用每库进程锁，避免并发导入、渲染和导出；读取和进度
  保存继续可用。
- 桌面包与独立 CLI 包使用同一源码、组件版本和 MIT 许可证。
- 官网与 README 提供把仓库链接交给智能体的安装入口；日常可用自然语言交代检索和组稿任务。

## 安装桌面

解压桌面 ZIP，将 `DeckAtlas.app` 放入 `/Applications`，安装 LibreOffice 后打开。
首次导入一份熟悉的 PPTX，搜索关键词、预览选片、排序并导出，再用 PowerPoint 检查。
保留源文件。应用升级时也保留原资料库与设置；先退出旧应用并备份数据再替换应用。

包只有 ad-hoc 签名，没有 Developer ID 和公证。下载后 Gatekeeper 可能拒绝打开。
核对仓库来源及校验值后，参考
[Apple 安全打开应用说明](https://support.apple.com/102445)；不能接受此条件时先使用源码。
不关闭 Gatekeeper、不清除整个系统或用户目录的安全属性。

HTML 默认关闭。需要实验时，可在终端使用下列方式启动；需本机 Chrome：

```bash
PPTLIB_ENABLE_HTML=1 \
  /Applications/DeckAtlas.app/Contents/MacOS/DeckAtlas \
  --password-store=basic --use-mock-keychain
```

这会启动一个持续运行的桌面会话。HTML 支持可识别的静态演示页和安全 ZIP；在线抓取不携带
登录态、不执行来源脚本。登录页面、内网地址、纯脚本应用不支持。

## 安装 CLI / 给智能体

把仓库链接和“安装 DeckAtlas，并连接我已有资料库”的请求交给具有本机命令能力的 Agent。
仓库的 [接入说明](../../website/agent-setup.md) 包含安装、连接和任务编排。

手动安装时，将独立 CLI ZIP 解压到自己选定的位置，保留整个 `deckatlas/` 目录。运行
`deckatlas/deckatlas`，或将其所在目录加入 PATH。不要只复制单一二进制到其他目录。

配置 `PPTLIB_HOME` 为桌面正在使用的资料库，将 `PPTLIB_OUTPUT_ROOT` 设为允许输出的目录。
新安装默认桌面库位于 `~/Library/Application Support/DeckAtlas/data`；升级时可能继续引用
旧库，已选择其他资料库时以桌面显示的实际位置为准。CLI 输出 JSON，依赖宿主 Agent 把自然
语言转成检索、读页、选片与导出。

```bash
export PPTLIB_HOME="$HOME/Library/Application Support/DeckAtlas/data"
export PPTLIB_OUTPUT_ROOT="$HOME/Documents/DeckAtlas Exports"
./deckatlas/deckatlas capabilities
./deckatlas/deckatlas search --query "供应链"
```

初始库为空时需要先导入。`import <文件> --allow-write` 接受明确的本地文件，PPTX 预览
需要 LibreOffice、HTML 预览需要 Chrome；无需额外的 Python / Node。不要上传敏感材料给
外部 Agent，除非用户明确允许。导出必须预检并在输出目录内完成，详见
[CLI 协议](../../documentation/agent-cli.md)。

## 格式与限制

- PPTX 选片组合为可编辑 PPTX；母版、主题和关系依赖会复制，复杂媒体、OLE、外部对象仍需
  根据预检核对，不能承诺任意稿件完全保真。
- HTML 或混合选片可导出离线 HTML / ZIP，CLI 需 `PPTLIB_ENABLE_HTML=1`。其中 PPTX 页
  是高清图片。HTML 不自动变成可编辑 PPTX。
- 本地源文件长期保留，移走或变更后导出可能被拒绝。首次索引和渲染耗时并占用缓存。
- 尚未关闭桌面主进程路径授权缺口；若可信 renderer 被攻破，可请求未通过对话框授权的本地
  路径。当前不是对外承诺的完整沙箱。
- 真实渲染取消、大库性能、VoiceOver、干净机器安装和旧版升级仍需持续验收。
- 没有自动更新或已认证的更新链；仅从本仓库下载，手动升级并保留数据。
