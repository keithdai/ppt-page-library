# Archived DeckAtlas Documents

Files in this directory are retained only for traceability. They describe earlier plans, prototype
layouts or assumptions that may no longer match the current implementation.

- `plans/`: completed implementation plans.
- `specs/`: superseded design and research specifications.
- `mockups/`: historical UI prototypes.
- `legacy/`: early project-wide design documents.

Do not implement from these files without reconciling them against
[`../../documentation/architecture.md`](../../documentation/architecture.md) and current code.
Active requirements belong one level up in `docs/`; current implementation facts belong in
`documentation/`.
