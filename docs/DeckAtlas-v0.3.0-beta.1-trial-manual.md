# DeckAtlas v0.3.0-beta.1 试用功能手册

## 1. 试用说明

- **适用版本**：`v0.3.0-beta.1`
- **试用周期**：2026 年 10 月 7 日至 10 月 13 日
- **复盘时间**：2026 年 10 月 14 日
- **试用目标**：验证“导入 PPTX → 找到页面 → 选片排序 → 组合导出”的真实工作闭环。
- **本周原则**：只修复核心闭环阻断、数据安全问题和高频严重问题；体验优化与新增需求先记录。

当前试用包是本地 macOS 应用。索引、缩略图、高清预览、选片和任务记录都保存在本机，
源 PPTX 不上传、不复制、不移动。

## 3. 启动与首次检查

当前应用位置：

`desktop/dist/mac-arm64/DeckAtlas.app`

启动后先观察顶部环境状态。正常情况下应满足：

1. SQLite 与本地搜索可用。
2. LibreOffice 与 PDF 预览渲染可用。
3. 本地数据目录和导出目录可写。
4. 页库自动恢复，不需要重新导入已有页面。
5. 上次选片顺序可以恢复。

如果启动后页库为空，不要立即重新导入全部文件。先点击“刷新页库”；仍为空再记录问题。

## 4. 导入并渲染

### 4.1 支持的操作

- 选择一个或多个 `.pptx` 文件。
- 选择一个或多个文件夹，递归扫描其中的 PPTX。
- 同一文件重复导入时，未变化内容直接跳过。
- 文件内容变化时生成新索引和预览。
- 文件只发生移动或改名时，尽量复用已有索引。
- 导入过程显示文件级、页级进度和失败原因。

### 4.2 预期结果

- 每页生成缩略图和高清预览。
- 16:9 页面高清预览通常为 `1920 × 1080`。
- 页面正文、备注和来源信息进入本地搜索。
- 页面得到业务主题、子主题和页面用途分类。
- 导入完成后页库自动增量刷新，不重新加载全部页面文本。

### 4.3 注意事项

- 源文件必须保留在原位置；DeckAtlas 只记录路径和内容哈希，不保存 PPTX 副本。
- 超大文件、损坏文件或结构异常文件可能无法由 LibreOffice 打开。
- 包含外部 Excel、外链图片、外链音视频或外部对象的稿件可能被安全策略拦截。
- 普通网页超链接可以保留；真实外链媒体应先嵌入 PPTX，再重新导入。
- 导入失败不会删除已有可用预览；旧缓存会保留。
- 导入过程中不要同时移动、改名或覆盖源文件。

## 5. 页库浏览与搜索

### 5.1 文件目录

左侧按本地来源目录展示稿件。点击文件后，中间区域加载该文件的页面。

当前架构按需读取：

- 左侧只加载文件元数据。
- 中间页面按批次加载，每批最多 100 页。
- 点击“继续加载”可查看后续结果。
- 点击“刷新页库”只更新有变化的内容。

### 5.2 搜索范围

- **当前文件**：只在左侧当前选中的 PPTX 中搜索。
- **全部页库**：跨全部稿件搜索。

搜索内容包括：

- 页面标题、正文和备注。
- 来源文件名和本地目录。
- 业务主题、子主题和页面用途。

可继续叠加“页面类型”筛选。搜索结果较多时，左侧文件数代表完整命中范围，不只统计当前
已加载的 100 页。

### 5.3 建议试法

本周至少分别尝试：

1. 一个页面标题关键词。
2. 一个正文中的业务词。
3. 一个文件名。
4. 一个目录名。
5. 一个中文短语。
6. 一个英文产品名或缩写。

重点记录“明明记得有，但搜不到”的案例；这类案例比单纯的搜索速度更重要。

## 6. 预览与放映

### 6.1 支持的操作

- 点击缩略图进入高清预览。
- 使用左右方向键切换当前结果中的页面。
- 按 `F` 进入或退出全屏。
- 按 `Esc` 退出预览。
- 全屏状态下，标题、页码和选片按钮隐藏；导航控件在悬停时显示。
- 可在预览浮层中直接加入或移出选片。

### 6.2 注意事项

- 预览由 LibreOffice 渲染，不等同于 PowerPoint 原生排版引擎。
- 字体缺失会导致替换字体、异常换行、文本重叠或版式漂移。
- 当前机器已补充常用字体，但从其他电脑迁移应用后仍需重新检查字体环境。
- 极窄文本框即使字体齐全，也可能因 LibreOffice 与 PowerPoint 的字宽差异发生掉行。
- 隐藏页会被正常生成预览；如果加入选片并导出，隐藏页会变为普通可见页。

## 7. 选片

### 7.1 支持的操作

- 从不同 PPTX 中持续加入页面。
- 在缩略图卡片或高清预览中加入、移出选片。
- 右侧选片单显示来源文件和页码。
- 拖拽调整输出顺序。
- 一键清空当前选片。
- 刷新窗口或重启应用后恢复已保存选片和顺序。

### 7.2 注意事项

- 当前同一页面只能加入一次。
- 删除仍被选片单引用的页面会被系统阻止；需要先移出选片。
- 选片单保存的是页面与源版本引用，不是源页面副本。
- 如果源 PPTX 在选片后被修改、移动或删除，导出预检可能阻止继续。

建议本周至少完成一次 **跨 3 份以上源稿、10 至 20 页**的真实选片。

## 8. 组合导出

### 8.1 操作步骤

1. 在选片区完成页面选择和排序。
2. 点击“用选片进入组合”。
3. 选择输出 `.pptx` 的保存位置。
4. 保持“导出前校验源文件未发生变化”开启。
5. 执行导出前检查。
6. 确认后生成 PPTX。
7. 从结果页打开文件或在 Finder 中显示。

### 8.2 导出方式

组合导出不是把预览图贴回 PPT，而是复制源页面的原生 OOXML 结构及其关联资源，保留：

- 页面元素和可编辑文本。
- 母版、主题和页面关系。
- 页面引用的图片、媒体和链接。
- 选片顺序及来源清单。

### 8.3 可能阻止导出的情况

- 源文件丢失。
- 源文件内容哈希已经变化。
- 选片中混入当前正式包不支持导出的 HTML 页面。
- 不同源稿的页面尺寸不兼容。
- PPTX 包结构损坏。

### 8.4 导出后的检查

每次真实导出至少检查：

1. 页数和顺序是否与选片一致。
2. 中文字体、英文缩写和数字是否换行。
3. 白色文字是否错误变成黑色。
4. 图片、图表、视频和外链是否符合预期。
5. 文件能否在 PowerPoint 中正常打开和继续编辑。

普通外部超链接被保留时，保真等级可能显示为 B；这不等于视觉渲染失败。

## 9. 重复管理

### 9.1 支持的操作

- 扫描整个本地页库。
- 按结构、视觉和文本识别确定重复与疑似重复。
- 系统默认勾选较保守的可清理页面。
- 用户可人工对比并调整选择。
- 批量从页库删除重复页面。

### 9.2 注意事项

- 删除只影响 SQLite 索引和本地预览缓存，不删除源 PPTX。
- 仍被选片单引用的页面不能删除。
- 疑似重复不等于可以安全删除，必须人工确认。
- 当前不做跨文件页面的自动合并，也不会自动替换选片引用。

## 10. 自动更新

### 10.1 支持的操作

- 一个计划管理多个文件夹。
- 设置文件类型、文件大小范围和执行时间。
- 保存前预检预计新增、更新、跳过和异常文件。
- 手动执行全部计划或单个目录。
- 查看当前进度、停止任务和运行历史。
- 设置每日执行时间与允许执行窗口。
- 修复旧版或缺失预览。

### 10.2 运行条件

- DeckAtlas 应用必须保持运行。
- 电脑必须保持唤醒。
- 调度器每分钟检查一次计划。
- 不安装 `cron`、`launchd` 或隐藏后台服务。
- 导入、组合、重复扫描和自动更新同一时间只能运行一个。

### 10.3 安全默认值

- 源文件暂时不可用时，默认保留页库记录，不自动删除。
- 删除策略固定为“保留”后再由用户人工处理。
- 文件夹失去访问权限时，计划会提示重新授权。

本周建议先使用“预检”和“立即更新”；确认行为符合预期后，再开启每日自动更新。

## 11. 删除与数据安全

### 11.1 从页库删除

- 文件级删除：移除该文件及页面的索引与预览缓存。
- 页面级删除：只移除该页索引与预览缓存。
- 两种操作都不会修改、移动或删除源 PPTX。

### 11.2 本地数据

- 数据库：`var/dev/pages.db`
- 缩略图与高清预览：`var/dev/assets`
- 导出文件：以组合导出时选择的保存位置为准；现有测试与历史导出位于 `var/dev/exports`
- 源 PPTX：仍位于用户原目录，不计入 DeckAtlas 自身占用。

不要手动删除 `pages.db` 或 `assets`。需要清理时，应使用应用内删除功能。

## 12. 当前已知限制

1. `v0.3.0-beta.1` 正式打包版默认关闭 HTML / ZIP 演示稿能力，本周只验证 PPTX。
2. LibreOffice 与 PowerPoint 的字体度量存在差异，紧凑文本框可能出现轻微版式偏差。
3. 缺失字体、外链媒体、外部 Excel、OLE 或异常包结构可能导致渲染失败。
4. 少数超大或复杂稿件可能只能保留旧预览，无法完成本轮刷新。
5. 自动更新不唤醒电脑，也不会在应用完全退出后运行。
6. 当前没有设置中心和存储中心；相关能力计划在试用期后进入 Phase 1。
7. 当前没有多人共享、云端源文件托管和跨设备同步。
8. 内部试用包尚未配置正式 Developer ID 签名、公证和自动更新发布。

| 第 7 天 | 重复一次完整闭环 | 第二次使用是否明显更顺手 |

## 14. 问题反馈格式

发现问题时，尽量记录：

```text
时间：
所在步骤：导入 / 搜索 / 预览 / 选片 / 导出 / 重复管理 / 自动更新
操作对象：文件名可脱敏，注明大致页数和文件大小
操作步骤：
预期结果：
实际结果：
是否可以稳定复现：
是否阻断继续工作：
界面错误文字或底部日志：
```

问题优先级：

- **P0 数据安全**：源文件被修改或删除、数据库损坏、选片丢失、出现钥匙串弹窗。
- **P1 核心阻断**：无法启动、导入、搜索、选片或导出。
- **P2 体验与保真**：排版偏差、搜索不准、交互不顺、提示不清楚。
- **建议项**：新功能、视觉优化和流程增强。

本周即时修复 P0/P1；P2 与建议项统一进入 10 月 14 日复盘。
