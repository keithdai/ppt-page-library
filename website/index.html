01 / 你的困扰

大文件里的一页案例，
人和 AI 都难找。

准备一份新方案时，这四幕可能每天都在发生。

把文件里的内容变成可检索的页面，给人和 AI 同一个复用入口。

以上为场景插画。单份 PPT 中可以查找文字；这里解决的是跨文件的页级索引与复用。首次导入仍需解析和生成预览，源 PPT 大小不会改变，也不会自动缩小其中的图片或视频。

02 / 工作流程

导入旧稿，找到页面，
组成下一份。

源文件仍由你管理。DeckAtlas 负责索引、预览、选片和组合。

  1. 01 / 建立页库

    把常用旧稿导进来

    选 PPTX 文件或整个文件夹。本地拆页、提取标题、正文和备注，生成缩略图与高清预览。

    结果：文件里的内容，能按页搜索
  2. 02 / 搜索与选片

    先看清，再加入选片

    搜关键词，结合分类和页面用途筛选。打开大图确认，从不同稿件持续加入页面，选片顺序会保存。

    结果：跨稿素材，集中到一张选片单
  3. 03 / 组合导出

    排好顺序，检查后导出

    拖拽排序，选择保存位置，再预检源文件和格式。PPTX 页面导出为可继续编辑的新 PPTX。

    结果：拿到新稿，继续在 PowerPoint 编辑

索引一次，之后按页查找先解析源稿并生成预览，后续浏览页库无需为看一页反复打开整份稿。首次导入时间随页数、文件复杂度和本机环境变化。

常用目录持续更新先预检新增与变化，再手动或按计划更新；定时执行需要应用运行、电脑唤醒。

资料留在本地本地源文件只读引用；清理页库只移除索引和缓存，被已保存选片引用的页面会受到保护。

不同素材，选合适的输出

HTML 为实验能力
素材来源可以做什么输出与边界
PPTX 文件 / 文件夹导入、搜索、高清预览、跨稿选片组合为可编辑 PPTX；复杂媒体或外部对象以预检提示为准。
HTML / ZIP / 在线演示识别演示页面、静态归档、隔离预览输出离线 HTML 或 ZIP；网页演示需有可识别的静态页面结构。

v0.3.0-beta.1 打包版默认关闭 HTML，源码桌面模式默认开启。在线归档会下载资源并保存本地快照，不携带登录凭证、不执行来源脚本；登录态、内网地址和纯脚本页面不支持。视频、GIF 和部分 CSS 交互以实际兼容性提示为准。

03 / 快速上手

先用一份旧稿，
走完一次复用。

从熟悉的材料开始：你知道里面有什么，也更容易判断搜索、预览和导出是否符合预期。

  1. 01

    启动并检查环境

    安装 LibreOffice，打开 DeckAtlas，确认本地搜索与预览渲染可用。

  2. 02

    导入一份熟悉的 PPTX

    等待索引和预览生成。保留源文件，后续导出还需要读取它。

  3. 03

    搜一个你记得的词

    尝试案例名、正文关键词或备注里的词。打开高清预览，选中需要的页面。

  4. 04

    排序、预检、导出

    从选片进入组合，选保存位置，执行检查后生成 PPTX。用 PowerPoint 核对顺序和排版。

目前可从源码运行

第一次启动

公开安装包尚未开放。熟悉终端的用户可在 macOS 上先安装 Python 3.11、Node.js 20、Git 和 LibreOffice，再运行以下命令。

终端 / 获取源码并启动
git clone https://github.com/keithdai/ppt-page-library.git
cd ppt-page-library
make install
npm --prefix desktop install
export PPTLIB_HOME="$PWD/var/dev"
npm --prefix desktop start

这里将体验资料库放在仓库的 var/dev 中，CLI 示例也使用同一个目录。请保留该目录；已使用其他资料库时，改为你原有的数据目录。

开始前，你可能还想知道

导出后还能编辑吗？版式会变吗？

PPTX 组合复制原生页面及关联资源，文本与元素可继续编辑；复杂媒体、OLE 和外部对象可能有兼容性限制。预览由 LibreOffice 渲染，字体缺失或字体度量差异可能影响显示。导出后请在 PowerPoint 中核对。

我的源文件和资料库会怎么保存？

本地源 PPTX / HTML 只读引用，不上传或移动。索引、预览和选片记录保存在本机，在线归档会另存资源快照。换版本前保留原资料库和源文件；从页库删除只清理索引与缓存。

任意网页都能归档吗？

需要有可识别的静态演示页面，如 .slide 或 Reveal section。登录态页面、内网地址、依赖脚本生成的页面和普通网页不在支持范围内。CLI 导入仅接受本地文件，在线归档使用桌面端。

现在支持 Windows 或 Intel Mac 吗？

当前桌面构建面向 Apple Silicon Mac。Windows 和 Intel Mac 尚未完成打包与验证。

使用中遇到问题，在哪里反馈？

在 GitHub Issues 中记录版本、操作步骤、预期结果和实际错误。提交前去除客户内容、私人路径等敏感信息。
